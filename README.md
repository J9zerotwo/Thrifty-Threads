# Thrifty Threads

Thrifty Threads is a web-based e-commerce platform designed for buying and selling second-hand or pre-loved clothing and items. The platform provides a convenient and user-friendly shopping experience with features such as user authentication, product browsing, shopping cart management, secure checkout, and order tracking.

## Features

### User Accounts

Users can create and manage accounts to securely save personal information, shipping details, and order history for a smoother checkout experience.
